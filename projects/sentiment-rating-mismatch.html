PROJECT 05

Large-Scale Sentiment–Rating Mismatch Detection

Independent Project Sep 2025 – Dec 2025 Solo

Overview

A distributed data pipeline processing large-scale Amazon review data to surface cases where written sentiment disagreed with the numeric star rating, a signal useful for review-quality and fraud detection.

Approach

  • Built a distributed PySpark pipeline on GCP Dataproc to process review data at scale, with outputs written to Google Cloud Storage.
  • Applied TF-IDF and Word2Vec representations alongside K-Means clustering, LSH, and LDA topic modeling to characterize review content.
  • Flagged sentiment–rating mismatches as a proxy signal for unreliable or manipulated reviews.
