PROJECT 08

Voice-to-Voice Agentic Product Discovery Assistant

Team Project Jul 2026 with Aren Mizuno

Overview

A voice-to-voice, multi-agent e-commerce assistant that understands spoken product requests, plans a retrieval strategy, pulls grounded and cited evidence from a private product catalog (with optional live web reconciliation), and responds via speech with on-screen citations. A LangGraph state graph (Router → Planner → Retriever → Answerer/Critic) orchestrates two MCP tools — a Chroma-backed rag.search over the full Amazon Product Dataset 2020 (10,002 products) and a domain-allowlisted web.search — behind a FastAPI backend and React frontend, with faster-whisper transcription and Azure TTS synthesis closing the voice loop.

Approach

  • Built a Kaggle-sourced ingestion pipeline (download → schema inspection → cleaning → embedding → indexing) turning the full Amazon Product Dataset 2020 — 10,002 products across every category — into a persistent Chroma vector index, with category stored as filterable metadata rather than pre-filtered at ingestion, and diagnosed real data-quality issues (empty brand/ingredient fields, no ratings column, ~4% malformed price strings) with a dedicated parser rather than silently ingesting noisy data.
  • Built an MCP server exposing rag.search and web.search (Serper.dev Shopping with a domain-allowlisted, robots.txt-respecting organic-search fallback) as the only interface the agent graph is allowed to call through — with response caching, rate limiting, and full request/response logging.
  • Implemented the LangGraph Router → Planner → Retriever → Answerer/Critic flow on the Claude API through a swappable provider abstraction, with a relevance-judgment call gating whether the private catalog genuinely satisfies a query before falling back to live search, and follow-up queries ("the cheapest one") resolved against conversation history instead of re-querying from scratch.
  • Closed the voice loop end to end — faster-whisper transcription in, Azure TTS synthesis out — behind a FastAPI backend and a React frontend with mic capture, a live transcript, an agent step log, a comparison table, and citations.
  • Ran two evals against the real, live agent graph rather than mocks: a 10-case golden query set that caught and fixed a real bug (rejected private-catalog hits were leaking into the Answerer's evidence after being judged irrelevant), reaching 10/10 passing after the fix; and an adversarial proofagent-harness eval that caught a second real bug (an unhandled Serper API error crashing the whole agent turn) and, after fixing it, scored 83% task success, 94% hallucination resistance, 100% instruction following, and 100% manipulation resistance and safety — earning a SILVER certification.
