PROJECT 08

Personal Portfolio Website

Independent Project 2026 Solo

Overview

The portfolio site you're looking at right now: a static, framework-free multi-page site (Home, Projects, Coursework, and individual detail pages) built entirely from a Python template generator, with a custom hand-drawn design system tying together painting, data, and code.

Approach

  • Designed a custom token system — a warm-paper palette with indigo and ochre accents, Fraunces/Inter/IBM Plex Mono type pairing, and a hand-drawn brush-stroke signature motif nodding to an oil-and-charcoal painting practice.
  • Built a Python generator (build.py) that templates all pages — shared nav, footer, and layout — from structured project and coursework data, so content changes never require hand-editing HTML.
  • Implemented an embedded résumé viewer, card-grid index pages, and detail pages with linked repos and documents for every project and course.
  • Shipped as plain static files with zero build step, deployable via GitHub Pages, Netlify Drop, or Vercel.
