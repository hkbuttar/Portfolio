PROJECT 08

Personal Portfolio Website

Independent Project 2026 Solo

Overview

The portfolio site you're looking at right now, rebuilt as a small but real static-site pipeline: content lives as validated YAML data, templated through Jinja2 into static HTML, tested and auto-deployed via GitHub Actions. The visual design — a hand-drawn brush-stroke motif nodding to an oil-and-charcoal painting practice — is unchanged from the original version; only the build system underneath it changed.

Approach

  • Separated content from code: every project and coursework entry is its own YAML file under data/, validated against a schema (content/schema.py) that fails the build with a clear file name and reason on any malformed entry, rather than producing silently broken HTML.
  • Replaced hand-written f-string HTML generation with Jinja2 templates using proper inheritance and shared partials (nav, footer, card grid, PDF/PPTX preview cards), so a layout change propagates everywhere from one file.
  • Wrote a test suite (schema validity, slug uniqueness, link hygiene, document-folder sync) and a GitHub Actions workflow that runs the tests, builds the site, and deploys to GitHub Pages automatically on every push — verified the whole pipeline end to end, including deliberately breaking a YAML file to confirm validation actually catches it.
  • Built a document-preview system for the Links & Documents section: PDF links render as live first-page thumbnails that open in an in-page lightbox on click; PPTX links get a styled placeholder card, since browsers can't render PowerPoint natively.
